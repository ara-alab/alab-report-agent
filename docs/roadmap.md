# 로드맵

MES/ERP 연계 보고서 기안 AI Agent의 단계별 목표와 범위

| 단계 | 목표 수준 | 핵심 범위 | 완료 기준 |
| --- | --- | --- | --- |
| 1. MVP | Level 3(MVP) | 자연어 요청 기반 조회·분석·기안, 대화 수정, 근거 추적·검증, 보고서 저장·통합 | 시연 시나리오가 반복 실행되고 목표 성능 4종이 측정됨 |
| 2. 고도화 | Level 3 확장 | 서식·조회 함수·테이블 확대, 이상 탐지 고도화, 기업 HWPX 양식 반영 | 생산·품질·설비 보고서가 복수 서식으로 생성됨 |
| 3. 파일럿 | Level 4(Pilot) | 실제 MES/ERP·설비 센서 로그 연계, 데이터 표준화, 실사용자 반복 검증 | 실데이터·현장 조건에서 작성 시간 절감 효과가 측정됨 |
| 4. 확장 | 제조 AX 확장 | 업무 영역 확대, 외부 제조 AI 모델·업무시스템 연계 | 보고 외 제조 업무 Agent가 동일 구조로 추가됨 |

## 1. MVP

- 범위와 일정: [MVP 구현 계획](mvp-plan.md)
- 메인 흐름: 대화로 시작, 템플릿으로 시작
- 확장 흐름: 저장된 Agent 보고서 기반 보고서 통합
- 데이터: 가상 MES 스키마와 시드 데이터

## 2. 고도화

- 서식: 생산·품질·설비 보고 서식 추가, 기업 표준양식(HWPX) 기반 서식 등록
- 데이터: 생산계획 등 테이블 추가, 조회 함수 레지스트리 확대
- 분석: 규칙 기반 이상 판정에서 추세·통계 기반 이상 탐지로 확대
- 출력: HWPX/DOCX 출력의 표·서식 재현 범위 확대

## 3. 파일럿

- 연계: 실제 MES/ERP API·DB 연계, 실제 설비 센서 로그 연계, 데이터 표준화 모듈
- 검증: 실사용자 반복 사용, 작성 시간·수치 일치율 등 효과 측정
- 운영: 계정·권한을 실제 인증 체계와 연동

## 4. 확장

- 업무: 경영 보고 등 제조 업무 Agent로 확대
- 연계: 외부 제조 AI 모델과 기업 업무시스템 연계
- 운영: 보안·모니터링·유지보수 체계
