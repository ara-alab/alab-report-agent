# 대회 과제 개요

제4회 경남 AI·SW 경진대회 출품 기준의 주제·문제·Agent 역할·핵심기능·Workflow·시연·성과지표 요약

## 1. 주제 선택

| 항목 | 내용 |
| --- | --- |
| 지정주제 | 03 제조·피지컬 AI |
| 소주제 | 우리 삶(L.AX)과 산업(M.AX, P.AX)을 바꾸는 똑똑한 AI Agent |
| 피지컬 AI 요소 | 설비 센서 로그를 규격과 대조해 이상을 판정하고 보고서 근거로 사용 |
| 데이터 방식 | 실제 장비 미연동, 생성기로 만든 시뮬레이션 센서·MES/ERP 데이터 |

## 2. 문제 정의

| 항목 | 내용 |
| --- | --- |
| 사용자 | 생산·품질 보고서 기안자와 검토·승인자 |
| 문제 | 기안자가 MES/ERP·센서 로그를 직접 조회·집계하고 서식에 옮겨 적는 반복 작업 |
| 위험 | 수치를 손으로 옮겨 적는 과정의 오류, 이상 원인의 근거 누락 |

## 3. Agent 역할

- 설비 측정값과 MES/ERP 데이터를 조회·분석해 이상을 판정하고, 그 근거를 붙여 보고서를 기안하는 AI Agent

## 4. 핵심기능

| 기능 | 내용 |
| --- | --- |
| 1. 자연어 요청 기반 데이터 조회 | 요청에서 기간·대상·지표를 해석해 조회 계획을 세우고 MES/ERP·설비 측정 데이터 조회 |
| 2. 설비 측정값 이상 판정 | 측정값을 설비 구분별 규격과 대조해 이탈 항목·시각 판정 |
| 3. 이상 구간 영향 분석 | 이탈 구간의 생산·품질 실적과 KPI·직전 기간 증감 산출 |
| 4. 서식 보고서 기안·수정 | 이상 원인과 근거를 담은 서식 보고서 기안, 대화 지시로 섹션 재작성 |
| 5. 근거 추적·정합성 검증 | 수치별 출처 기록, 원본 재조회로 보고서 수치 대조 |

## 5. Workflow

| 단계 | LLM | Tool(코드) |
| --- | --- | --- |
| 계획 | 요청 해석, 조회 계획 수립 | 기간 산출 |
| 조회 | 조회 함수 선택, 부족하면 SQL 작성 | 조회 실행, SQL 가드 검증 |
| 분석 | 추가 조회 여부 판단 | KPI 계산, 규격 이탈 판정 |
| 기안·수정 | 원인·서술 작성, 섹션 재작성 | 서식 키 매핑, 계산값 기입 |
| 검증 | — | 원본 재조회 대조 |

- Tool의 수치 산출·이상 판정·정합성 검증은 자체 작성한 산출·검증 알고리즘 사용
- 단계별 상세: [MVP 구현 계획 §5 시연 시나리오](mvp-plan.md#5-시연-시나리오)

## 6. 시연 상황과 성공 조건 (후보)

| 안 | 사용자·상황 | 성공 조건 |
| --- | --- | --- |
| A | 품질보증팀 서민재, 9월 4주 품질 보고서 요청(`vibration-spike`) | 요청 1회로 초안 생성, 원인으로 진동 규격 이탈 항목·시각 제시, 보고서 수치 원본 대조 일치 |
| B | 생산기술부 김도현, 9월 2주 생산실적 보고서 요청(`post-pressure-stop`) | 압력 저하에 따른 STOP 구간과 양품 감소가 수치와 함께 보고서에 기재 |
| C | 이상훈 부장, 하위 보고서 기반 통합 보고서 요청 | 통합 수치 → 하위 보고서 → 원본 순으로 근거 연결, 저장·통합 기능 구현 전제 |
